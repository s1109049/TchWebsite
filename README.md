# 課堂管理系統：多班科版 v4.3

以這次提供的 `index (2).html` 為藍本，保留原有五個分頁、字型設定、配色、卡片及課堂／家課／後台主結構。只修正資料讀寫問題，並在原有點名卡片內加入模式選擇。

## 班科首頁

開啟 HTML 先選科目及班別，共 11 個工作區：

| 科目 | 班別 |
| --- | --- |
| 中國歷史 | S1D |
| CL | S1D、S2A、S2B、S2C、S3B、S3C、S3D |
| 公經社 | S3A、S3B |
| 公社 | S4B |

同班不同科分開保存。每個工作區有自己的課堂流程、名單、家課交收、歷史、範本、語言及本輪抽選紀錄；切換時會鎖定後台、停止計時，避免誤改其他班。左上「選班」返回首頁。修改會嘗試自動存於此瀏覽器；這不是跨裝置同步或加密的帳戶系統。

**同一份 HTML 包含全部 11 個班科。** 儲存原檔、下載副本、匯出 JSON 都包含全部班科。換電腦請帶走最新 HTML／完整備份，不能只依賴本機快取。

匯入舊版單班 HTML／JSON 只取代目前所選班科；匯入新版完整備份會先明確確認，然後取代全部班科。不要把舊單班資料匯入錯誤科目。

## 只更新名單

支援 `rosterImportVersion: 1` 名單匯入檔，按班名自動填入對應科目（例如 S1D 會更新中史及 CL），保留原有流程、習作、歷史和範本。匯入前先下載完整備份，既有交收紀錄只保留學號及姓名相符者，並重設抽選名單。個人名單檔不放在公開儲存庫。

## 更方便建立流程

- 快速加入回顧、講解、課堂練習及總結，附常用時間。
- 每一步可直接修改、複製、上移、下移及刪除；編輯後即時顯示於前台。
- 展開「貼上多個流程步驟」可貼試算表三欄，或每行使用 `時間 | 標題 | 詳情`；只貼標題也可。
- 原有儲存流程範本、套用範本及課堂歷史保留，各班科獨立。

## 保留你原本資料的使用方式

GitHub 版本沒有放入附件中的學生姓名及個人課堂紀錄。請先保留舊 HTML 的備份，再：

1. 下載專案 ZIP，解壓後開啟 `index.html`。
2. 先選正確班別及科目，再進入「後台管理」，沿用原有管理密碼 `0926`。
3. 在原來的資料儲存中心，按「匯入舊 HTML / JSON」，選取你的 `index (2).html`。它只讀取檔案內的資料，不執行舊檔中的程式。
4. 核對課堂流程、學生、家課、範本及歷史紀錄。
5. 按「儲存並更新原檔」，首次選取要更新的原本 HTML 並授權。確認目標檔案後，修正後的程式及目前資料會一起寫入該檔。
6. 以後使用這份更新後的 HTML。相同瀏覽器、相同位置能保存檔案連線時，後續儲存會更新同一份 HTML，不會每次另開下載檔案。

匯入前會先產生目前資料的 JSON 安全備份下載。請確定安全備份已存妥；匯入資料後，仍需按儲存才會更新實體 HTML。

## 修正了甚麼

### 重新讀取後流程無法修改

原附件同時有兩個問題：

- 把登入後的現場 DOM 儲存進 HTML，重開時畫面仍顯示已解鎖，但程式的登入旗標是未登入，導致讀取編輯欄位的邏輯不執行。
- 語言初始化指向不存在的 `txt-login-err` 元素，引發錯誤，中斷後續初始化。

修正後，重開會顯示正常的登入狀態。登入後每個流程欄位直接更新資料；儲存時不再由隱藏／舊的輸入框重新拼裝流程。新增步驟不會覆蓋剛輸入的文字，只有詳情的步驟也會保留，刪除最後一步能正確儲存空流程。輸入雙引號及 HTML 符號也不會破壞編輯框或匯出的檔案。

### 儲存直接更新原本 HTML

- 原本的「儲存課堂」和儲存中心的主按鈕，現在都會更新已選取的 HTML。
- 使用 File System Access API；支援的瀏覽器會透過 IndexedDB 記住檔案控制代碼，重開時嘗試恢復連線。
- 只在檔案寫入及關閉成功後，回報原檔更新完成。
- 如果寫入期間又修改內容，會保留未儲存提示，提醒再儲存一次。
- 取消選檔、拒絕權限或寫入失敗時，保留本機修改，不會假裝已寫回 USB。
- 保留「下載副本」作為備份或不支援瀏覽器的替代方式。按主儲存鍵不會自動下載另一份 HTML。

**瀏覽器的檔案授權無法繞過。** 建議使用最新版桌面 Chrome／Edge。瀏覽器、學校裝置政策、檔案移動位置、權限到期或私密模式，可能使你需要重新選檔或授權。Firefox／Safari 等沒有此 API 的環境，請使用下載副本再手動覆蓋。

本機快取只是同一瀏覽器的備份，不能代替原檔更新；清除瀏覽資料或換電腦前請先儲存實體 HTML。檔案控制代碼的記錄依資料集及開啟路徑分開，避免另一份 HTML 誤寫到前一份檔案。

### 點名模式

在原來的「互動點名」卡片增加三個模式按鈕：

- **跑馬燈**：保留原來的大字結果卡。
- **輪盤**：轉動減速後，結果直接顯示在原有結果卡。
- **夾公仔**：夾臂移動、下降、夾起公仔，再顯示抽中的學生。機內展示全部尚未抽中學生的彩色編號球，每球下方有姓名；班級較大時可捲動查看。每一個球代表一位學生，抽選對象是所有未抽學生。

每個班科的三個模式共用同一輪防重複名單，動畫開始前決定結果。切換模式不會重設名單；全班抽完後需按原有「重置名單」開始新一輪。抽選過程會暫停模式切換與重置，避免連點衝突，並支援系統減少動態效果設定。

## 資料及版面

沿用原本 `lesson / students / homeworks / submissions / historyLessons / flowPresets` 資料格式；新增 `_storage` 僅供版本及本機備份辨識。舊 HTML／JSON 可直接匯入。

原版的 Google 圓體載入及系統備援設定原樣保留；沒有套用上一版重新設計的側欄、分區或內嵌字型。多班科資料使用 `workspaceVersion: 1` 外層封裝，仍保留每個班科原有資料格式。學生資料只在本機和你選擇的 HTML／JSON 中保存。後台密碼只是防誤觸，不會加密備份。

## 開發

執行建好的 `index.html` 不需要安裝套件。修改原始碼時：

```sh
npm ci --cache /tmp/tch-npm-cache
npm run build
npm test
```

- `src/shell.html`：清除個人資料及已儲存畫面狀態的原版 HTML 外殼。
- `src/style.css`：原版 CSS 原樣保留在前段，後段只增加點名模式及檔案控制樣式。
- `src/app.js`：原版應用程式，針對上述問題修改。
- `src/classes.js`：11 個班科首頁、獨立資料、整本備份及流程快捷操作。
- `src/extensions.js`：原檔儲存、備份、輸入同步、輪盤與夾公仔邏輯。
- `src/default-data.json`：不含個人資料的初始資料。
- `scripts/build.mjs`：產生單一 `index.html`；未建置前的原始碼修改不會出現在成品。

`npm start` 使用 Python 3，在 4173 埠啟動靜態伺服器。瀏覽器測試使用 `/usr/bin/chromium`，亦可透過 `CHROMIUM_PATH` 指定執行檔。

詳細證據與實體 USB 的驗證限制見 [測試紀錄](docs/VALIDATION.md)。
