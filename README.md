# 課堂管理系統 Classroom · v4.1

為課室投影、備課及家課交收設計的離線工具。依照提供的「教師課堂與家課管理系統」對話重新實作，重點是流程即時更新、資料可攜、清楚的儲存狀態與容易閱讀的畫面。

## v4.1 版面與操作

- 恢復原版的 **M PLUS Rounded 1c** 圓體與藍紫色頂部導覽。字型嵌入 HTML，離線也可載入，無需字型網站。
- 移除左側導覽與大幅標語，採用接近全螢幕寬度；課堂主題放在頂部，學習目標／公告與流程分欄。
- 單份家課採多欄學生名單，1440 × 900 桌面可同時查看 35 位示例學生；矩陣及單份檢視都保留右側未交名單。交收修改可撤銷，更新時保留捲動位置與鍵盤焦點。
- 後台分成「課堂編輯」「範本與歷史」「名單與習作」「儲存與備份」。底部固定儲存、預覽與下載按鈕；未加入的公告／器材欄位收起。
- 貼上但未匯入的名單在同一頁面切換工作區後仍保留；重新整理前仍需按「更新學生名單」。進行中的計時器在重設時先詢問確認。

## 直接使用

1. 下載本專案的 `index.html`，用瀏覽器開啟。這一個檔案已包含全部程式與樣式，無需網路、字型網站或安裝套件。
2. 進入「後台管理」，使用原對話設定的管理密碼 **0926**。密碼不會顯示在投影畫面；這只是防誤觸鎖，**不提供加密或真正的存取權限控制**。
3. 填寫主題、目標和流程，所有修改立即同步至「課堂內容」，並嘗試自動儲存到目前瀏覽器。
4. 上課前使用「下載離線 HTML」，把包含目前資料的新檔存到 USB。請確認使用的是新檔，下載不會自動取代舊檔。
5. 建議另存一份 JSON 備份。換電腦時可開啟匯出的 HTML，或在新版本系統匯入 JSON。

初次使用是空白資料，不會混入對話中示範用的學生名單。使用舊系統時，請先匯出 `data.json`，再於新版後台的「儲存與備份」選擇「匯入備份」。支援對話最後版本的 `lesson / students / homeworks / submissions / historyLessons / flowPresets` 格式。若舊版曾把同名學生的紀錄合併，匯入無法還原當時未區分的身份，請核對一次。

## 五個工作區

- **課堂內容**：學習目標、編號流程、可選器材與公告；查看上一課。新課會先封存舊課，載入歷史時也會先保存當前課。
- **互動點名**：跑馬燈及輪盤、右側大字結果、本輪已抽名單、不重複抽選；本輪紀錄可重開恢復。
- **課堂計時器**：空白任務框、三段字級、數字倒數與 52px 比例條、預設及自訂時長、暫停／繼續、可選完成音效。按實際截止時間倒數，避免背景分頁節流造成慢秒。任務、字級及計時進度在同一分頁重新整理後保留。
- **家課交收**：單份習作與全班矩陣、未交名單、搜尋、四種附文字的狀態。繳交率預設隱藏，計算時含已交和遲交。解鎖後台並開啟「編輯紀錄」才可修改，避免投影時誤觸。
- **後台管理**：即時編輯、流程增刪及排序、範本、歷史、CSV／TXT／貼上名單、習作管理、備份匯入匯出。

支援繁體中文、English、中英雙語及投影模式。M PLUS Rounded 1c 字型隨 HTML 一起打包，不會向 Google Fonts 發送請求。原字型未涵蓋的繁體中文字會使用與原版相同的系統字型備援鏈，因此這些字在不同電腦可能略有不同。手機版會調整為單欄並保留橫向導覽。

## 儲存方式：請分清楚這三件事

| 操作 | 實際效果 |
| --- | --- |
| 自動儲存／儲存課堂 | 儲存在此瀏覽器的 localStorage；不會寫到 USB，不會跨裝置同步。清除瀏覽資料或私密模式可能使其消失。 |
| 下載離線 HTML／匯出 JSON | 產生包含資料的下載檔；需自行確認下載成功及保存位置。HTML 可獨立使用，JSON 用於復原或升級。 |
| 連接／更新 USB HTML | 支援 File System Access API 的瀏覽器可選取本系統匯出的 HTML，授權後直接寫入。只在寫入及關閉檔案成功後回報成功；不支援或拒絕時可改用下載。 |

瀏覽器及學校電腦政策可能要求每次重新授權，無法保證靜默覆寫。重新開啟後需重新連接檔案。本系統不會試圖繞過授權，也不會把寫入失敗說成成功。

本機快取依資料集 ID 分開，避免不同備份互相污染；同一份資料比較版本號，載入較新版本。遇到損壞的快取會顯示警示，保留原始儲存；有效的 HTML 內嵌資料仍會載入。儲存空間不足時保留記憶體中的修改、顯示警示並提醒匯出。儲存失敗且未匯出時會嘗試提醒不要直接關閉。

同瀏覽器的兩個視窗修改相同資料時，偵測到另一視窗的更新會暫停編輯，讓你先備份再載入。這是單機工具，不是多人即時協作系統；建議同時只保留一個編輯視窗。

學生以獨立 ID 記錄，即使同名也不會共用交收狀態。名單每行一位，可讀取 UTF-8 CSV／TSV 的「學號、姓名」兩欄及常見表頭。更新時按姓名出現次序配對保留原紀錄；名單有同名學生而且排序改變時，請核對身份。移除學生或習作前建議備份。

資料只保留於瀏覽器與你匯出的檔案，不會傳送到第三方。**包含學生資料的 HTML／JSON 不應提交至公開 GitHub 倉庫或公開網站。** 尚未加入伺服器帳戶驗證、雲端資料庫或跨電腦同步。

## 開發與驗證

執行已建好的 `index.html` 不需要 Node.js。若要維護原始碼：

```sh
cd /workspace/TchWebsite
npm ci --cache /tmp/tch-npm-cache
npm run build
npm test
npm run test:e2e
```

- `src/core.js`：資料模型、備份驗證與舊格式轉換。
- `src/app.js`：操作、顯示與儲存；欄位直接更新模型，不會在存檔時從 DOM 重建資料。
- `src/shell.html`、`src/style.css`：畫面與離線樣式。
- `src/fonts/`：原版圓體字型、SIL OFL 1.1 授權與固定來源版本；授權內容也嵌入匯出的 HTML。
- `scripts/build.mjs`：把原始碼打包成單一 `index.html`；修改原始碼後必須重新建置。
- `npm start`：以 Python 3 在 4173 埠啟動開發用靜態伺服器；直接使用現有 checkout 即可。

瀏覽器測試預設使用 `/usr/bin/chromium`。其他系統可設定 `CHROMIUM_PATH` 指向 Chromium／Chrome 執行檔。Playwright 測試會自動啟動測試伺服器。

驗證範圍與限制見 [測試紀錄](docs/VALIDATION.md)。
