# 驗證與需求對照

本次以提供的對話作為產品需求來源，沒有沿用對話中「保證無 bug」「已完整實測」等缺少執行證據的宣稱。對話最後已移除的圓盤時鐘、座位表與討論句型卡不在本版加入。

## 主要改善

| 對話中的問題 | 本版處理 |
| --- | --- |
| 新增／刪除流程後文字不見、前台未更新 | 每一欄直接更新資料模型；重新繪製輸入框前不需要重新讀取 DOM。 |
| 刪光最後一步後，舊流程復活 | 空流程就是有效的空陣列，完整儲存及還原。 |
| 重開後資料不見、舊快取覆蓋新檔 | HTML 內嵌完整資料；同 ID 比較版本，匯入時建立獨立資料集。 |
| 不清楚儲存到底成功在哪裡 | 分開本機儲存、下載及 USB 寫入，成功訊息與實際操作一致。 |
| 匯出的 HTML 包含當時解鎖狀態或輸入框殘留 | 使用啟動時保留的乾淨頁面外殼，只嵌入 JSON 資料。 |
| 學生名／功課名有引號導致按鈕失效 | DOM textContent、事件監聽及獨立 ID；不把名稱拼入 onclick。 |
| 同名學生共用交收紀錄 | 每個學生有獨立 ID，逐一保留紀錄。 |
| 損壞備份蓋掉好資料 | 完整驗證後才匯入，替換前觸發目前資料安全備份下載。 |
| 輪盤結果太小 | 右側大字結果卡，無結果彈窗；支援減少動態效果偏好。 |
| 背景分頁讓計時變慢 | 以截止時間重新計算剩餘秒數，並以 sessionStorage 保留同分頁進度。 |

## 執行結果（2026-10-25）

執行環境：Node.js 24.19.0、npm 11.9.0、Python 3.12.14、系統 Chromium、Playwright 1.58.2。

- `npm run build`：產生單一離線 HTML。
- `npm test`：9 項通過，0 項失敗。資料與邏輯測試，涵蓋空白流程、重複姓名、CSV、舊版轉換、損壞備份、輪流抽點、截止時間、內嵌 JSON 安全。
- `npm run test:e2e`：19 項通過，0 項失敗。瀏覽器情境測試，涵蓋編輯、切頁、重開、最後一步刪除、歷史／範本、交收矩陣、獨立環境載入匯出檔、匯入、輪盤、計時、雙視窗、儲存失敗、手機版、中英切換及 USB 寫入的成功／取消／失敗。
- 1440 × 900 桌面及 390px 手機版已產生截圖並檢視；自動化另檢查 1280px 螢幕，涵蓋五個工作區的中、英及雙語模式。
- 原版 M PLUS Rounded 1c 的 400／800 字重均在瀏覽器顯示為 `loaded`，匯出的 HTML 於關閉網路的獨立環境也能載入字型。
- 35 人名單以三欄呈現，測試確認最後一位學生仍在表格可視範圍內。
- 新增測試驗證：單筆及整班交收修改撤銷、矩陣維持編輯欄位焦點與捲動位置、貼上名單草稿跨分頁保留、可選欄位收合、固定預覽按鈕、投影模式退出及運作中計時器重設確認。

## 驗證邊界

這台雲端機器的受管理 Chromium 禁止 `file://`，實際開檔嘗試收到 `ERR_BLOCKED_BY_ADMINISTRATOR`。因此離線測試以瀏覽器攔截器載入實際產出的 HTML，使用全新儲存空間並關閉網路，驗證無外部資源也能運作。沒有變更瀏覽器的管理政策；尚未宣稱實際 USB／file URL 開啟通過。

USB 檔案 API 在自動化測試中以替身檢查成功完成、使用者取消、權限拒絕與磁碟寫入失敗；雲端沒有連接實體 USB。Windows／macOS 的選檔器、學校裝置政策、重新授權及實際磁碟狀態需要在使用電腦驗證。

尚未執行 Firefox、Safari、真實課室投影或跨裝置同步測試。通過列出的測試代表已驗證這些情境，不代表所有環境都沒有錯誤。
