What is a spreadsheet?

Start here

A spreadsheet stores, organises, calculates, analyses and presents data. It contains cells arranged in rows and columns. Google Sheets and Microsoft Excel are examples of spreadsheet software.

01 · UNDERSTAND THE GRID

Rows, columns and cells

Concept

A column runs vertically (A, B, C). A row runs horizontally (1, 2, 3). Their intersection is a cell. Every cell has an address: column letter + row number.

Examples: B5 = Column B, Row 5. B3:B11 = all cells from B3 to B11 in one column.

05 · ONE CELL, ONE MINI CHART

The SPARKLINE function

Worksheet · Part 2

A sparkline draws a miniature chart inside a single cell. It reads a range of data and displays the trend without taking up space for a full chart.

Teacher's worked example · Minimum temperature · Cell B13
=SPARKLINE(B3:B11)

B = minimum temperature column; 3:11 = the nine forecast days.
