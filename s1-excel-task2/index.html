Before you solve the questions

How to hand in your work

Use the Excel workbook from Google Classroom. The PDF contains the questions; it is not the file you complete.

Your Classroom screenshot. Select the Microsoft Excel attachment inside the red box.
  1. 1
    Open the Excel attachment

    Open the assignment in Classroom. Select the file labelled Microsoft Excel, not the PDF.

  2. 2
    Download and open it

    Download the .xls file, find it in Downloads and open it in Microsoft Excel. If asked, enable editing.

  3. 3
    Complete and save your workbook

    Enter the formulas. Use File → Save As and name your file as shown below. Keep the .xls format if Excel asks.

  4. 4
    Attach your completed file

    Return to this assignment. Under Your work, choose Add or create → File → Upload and select your saved workbook.

  5. 5
    Click Hand in and confirm

    Wait for the upload, click Hand in, then confirm. Check that the status says Handed in.
