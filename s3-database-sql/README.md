# S3 Database & SQL Notebook

An English teaching website for S3 Computer Literacy. It reviews Activity WS1, explains the primary key through a library scenario, and demonstrates simple SQL using a fictional `Products` table.

## Open the lesson

Open `index.html` in a modern browser, or serve the folder as a static site. All essential resources are local; no installation or database server is required. The W3Schools practice link opens an external website.

The interactive notebook provides worked examples for SELECT, DISTINCT, WHERE, AND, OR, NOT, ORDER BY, IN, BETWEEN, MIN / MAX, COUNT and AVG / SUM. Choose an example and select **Run example** to compare its sample rows and output. These are fixed teaching examples, not a free-form SQL editor.

The `Library_Members` and `Products` records and the adapted hierarchy diagram use fictional data. The field names and Primary Key review connect to Activity WS1; the Products examples use different values from the W3Schools database.
