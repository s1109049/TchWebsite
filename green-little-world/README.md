# 綠意小天地 Green Little World

以 Three.js 製作的繁體中文科學小公園，讓學生沿着園內小路，遊覽花圃、大樹、草地、育苗區及回收站。透過近距離觀察、點選植物部位、拖動水壺及逐步查看生長示意，貫穿「認識花樹草、生長過程及生存條件」的科學課主題。

介面採用大物件、大按鈕、簡短指示及正向回饋，讓學生按自己的步伐學習。

**線上體驗：** <https://s1109049.github.io/TchWebsite/green-little-world/dist/>

## 互動內容

- **3D 公園遊覽**：從入口出發，按園內路牌或地點按鈕前往六個觀察點；鏡頭沿相連的小路移動，可用方向按鈕走近觀察、拖動畫面看看四周。
- **花、樹、草**：近看花瓣、莖、葉、樹幹、地下剖面中的根及草葉。點 3D 部位或大按鈕聽介紹，每站另有簡短觀察任務。
- **生長過程**：以一棵開花植物為例，由學生手動切換「種子、發芽、小苗、植株長大、開花」五個階段，觀察模型的改變。
- **生存條件**：認識陽光、水分和空氣；拖動 3D 水壺至植物旁或按澆水按鈕，學習適量澆水。澆水不會立即改變生長階段。
- **回收分類**：把 3D 回收物直接拖進回收箱，或先點物品拿起，再點回收箱。滑鼠與觸屏共用 Pointer Events 操作。
- **香港三色回收箱**：藍色收廢紙、黃色收金屬、啡色收塑膠。
- **六種回收物**：報紙、鋁罐、膠樽、紙盒、金屬罐、塑膠容器；可選基礎 3 件或進階 6 件。
- **學習支援**：中文語音優先選用粵語、加大文字、減少動態、鍵盤及 HTML 按鈕替代操作。減少動態時直接到達觀察點，省略鏡頭移動。
- **安心練習**：答錯會回位並提供提示；沒有計時或扣分，答對後自行按「下一個」。

語音使用裝置提供的聲音；即使沒有語音或 WebGL，仍可使用文字、圖片及大按鈕完成學習。網頁不收集學生姓名或作答紀錄，只在瀏覽器的 localStorage 保存顯示與語音設定。

生長動畫是概念示意，真正生長需要較長時間。種子發芽與小苗長大的條件並不完全相同；不同植物的光照、用水及生長速度也會不同。畫面先聚焦光、水、空氣，教師備註補充溫度、養分、空間，以及並非所有植物都必須種在泥土或都會開花等概念。

## 本機開啟

這是靜態網站，無須編譯、API 金鑰或後端。請用 HTTP 伺服器開啟，避免直接以 `file://` 載入 ES modules。

安裝 Python 3 後，在專案目錄執行：

```sh
python3 -m http.server 8000 --directory dist
```

然後開啟 <http://localhost:8000>。Windows 也可使用 `py -m http.server 8000 --directory dist`。

所有執行所需檔案均位於 `dist/`，可交由任何支援靜態網頁的主機服務提供。

## 檢查

使用 Node.js 22 或更新版本執行：

```sh
npm test
```

測試使用真正的 Three.js 幾何及 raycasting，搭配模擬 renderer／pointer events，檢查三種畫面尺寸、公園站點切換及抵達時序、植物部位點選、生長階段、水壺拖放、生存條件、取消操作、鎖定、動畫及資源釋放；另保留原有回收互動檢查。這些檢查不會啟動瀏覽器，仍建議在實際使用的平板、觸屏或電腦上試用。
