STEP 05 / THE IDEA

What is a primary key?

A primary key is a field whose value uniquely identifies each record in a table.

1

Unique

Two records cannot have the same primary-key value. 900101 and 900102 identify different records.

2

Not NULL

Every record needs a key value. A primary-key value cannot be missing (NULL).

3

Reliable to use

Choose an identifier intended to remain stable. A class can change and can be shared by many students.

Why is a key useful?

It helps the librarian locate, retrieve and update the correct member record.

What does it prevent?

A primary-key constraint prevents duplicate key values. Other fields such as names may still repeat.
